# Java Core

Bem-vindo ao meu repositório central de estudos e experimentações com a linguagem Java. 

Este projeto não é apenas um histórico de aprendizado, mas sim um **guia de referência pessoal e um laboratório prático** onde documento e testo os principais recursos da linguagem, desde os pilares da Orientação a Objetos até tópicos avançados como Concorrência, manipulação de I/O e comunicação com Banco de Dados.

## 🎯 Objetivo
Foi manter uma base de código organizada e de fácil consulta para conceitos do ecossistema Java por meio de Cursos e videoaulas, para garantir que a base teórica e prática esteja sempre afiada para o desenvolvimento de APIs e sistemas robustos.

---

## 📚 Índice de Conhecimentos Explorados

O repositório está estruturado progressivamente. Aqui estão os principais domínios abordados:

### 1. Orientação a Objetos e Fundamentos
A base estrutural para qualquer aplicação Java bem escrita.
*   **Classes, Métodos e Sobrecarga:** Estruturação básica e comportamentos.
*   **Construtores e Blocos de Inicialização:** Controle do ciclo de vida dos objetos.
*   **Pilares da POO:** Herança, Polimorfismo, Encapsulamento e Sobrescrita.
*   **Abstração e Contratos:** Classes Abstratas e Interfaces.
*   **Modificadores e Tipos:** Modificador Estático, Modificador Final e Enumerações.

### 2. Tratamento de Erros e Utilitários Core
Lidando com o comportamento dinâmico e recursos internos da JVM.
*   **Exceptions:** Tratamento de exceções checadas e não-checadas.
*   **Wrappers e Strings:** Manipulação avançada de tipos e textos.
*   **Datas e Formatação:** Trabalhando com o tempo no ecossistema Java.
*   **Regex e ResourceBundle:** Expressões regulares e internacionalização.

### 3. I/O, Arquivos e Serialização
Comunicação do código com o ambiente externo.
*   **IO e NIO:** Leitura e escrita de arquivos, manipulação de buffers e paths.
*   **Serialização:** Transformação de objetos para armazenamento ou tráfego.

### 4. Coleções, Generics e Java Moderno
Estruturas de dados eficientes e paradigma funcional.
*   **Generics & Collections:** Tipagem segura e manipulação de Listas, Sets e Maps.
*   **Classes Internas e Lambdas:** Sintaxe enxuta e funções anônimas.
*   **Streams API e Optional:** Processamento de dados fluente e prevenção de NullPointerException.
*   **Parametrização de Comportamento:** Tornando o código altamente adaptável.

### 5. Tópicos Avançados
Desempenho e integração com o mundo real.
*   **Threads e Concorrência:** Programação multithread, locks e sincronização.
*   **Design Patterns:** Padrões de projeto aplicados para resolver problemas comuns de arquitetura.
*   **JDBC (Java Database Connectivity):** Integração pura com bancos de dados relacionais.

*   **Paradigma:** Orientação a Objetos e Funcional
